# Vote Eligibility Checker

A beginner-friendly JavaScript DOM project for checking voting eligibility.
# Live Website
https://vote-eligibility-checker.netlify.app/

## Features
- User input handling
- Name validation
- Age validation
- Mobile number validation
- Date handling
- Voting eligibility checking
- Dynamic result display
- DOM manipulation
- Event handling

## Technologies Used
- HTML
- CSS
- JavaScript

## Purpose
This project was built to practice JavaScript fundamentals, DOM manipulation, events, conditions, and form validation.
